# 투찰 구간 보조 · 사용 설명서 · 산정 근거

사내 의사결정 보조 도구입니다. **자동 투찰·선정 보장이 아니며**, 최종 투찰가는 담당자가 직접 정합니다.

- 웹 주소: https://bid-assist-skylar1004-creator.vercel.app
- 대상: 자격·서류·마감을 이미 확인한 공고만

---

## 1. 사용 방법

### 1) 공고 불러오기

1. 나라장터 목록에서 **사업번호**를 복사합니다.  
   예: `R26BK01578429`
2. 화면 위 **사업번호** 칸에 붙여넣습니다.  
   (번호를 넣으면 자동으로 찾고, **불러오기**를 눌러도 됩니다.)
3. 공고명·수요기관·기초·추정금액·하한율·지역·종류가 채워집니다.

없으면 공개 공고 페이지에서 다시 가져옵니다. 그래도 안 되면 아래 칸을 직접 입력하세요.

### 2) 손익 하한 점검

- **실행원가**: 실제로 들어가는 비용
- **최소 수용 마진(%)**: 이보다 낮은 투찰은 경고

산정 3안과 별개로, **원가 아래로 내려가는지만** 경고합니다.

### 3) 신 판정 · 투찰가 (메인)

**AI 판정**이 메인입니다. 근거를 모아 투찰가 1개를 확정하고 확정칸에 넣습니다.

| 단계 | 내용 |
|---|---|
| 1 취합 | A/B/C/D + 유사기초 이력 재계산, 기초·하한 대비 ± |
| 2 정제 | IQR 이상치 제거, 합의 밀도 구간 탐색 |
| 3 전략 | 선정형=하한밀착+경쟁·합의 기반 전략틱 / 적격=합의 중앙 |
| 4 확정 | 신뢰도·판정 문장과 함께 금액 1개 출력 |

- 근거 없거나 기초가 대리값이면 **추천 없음**.
- **이 금액으로 간다**만 누르면 됩니다. 보조 안·이의제기는 대조용입니다.

### 4) 보조 안 · 전문가 이의제기

A/B/C/D 카드는 **대조**용입니다. 이의제기는 확정가가 하한·표본·원가에 어긋나면 돌려 말하지 않습니다.

### 5) 최종 결정

1. 신 판정 금액을 확인(또는 보조안/직접 입력)
2. 메모(선택) 후 **확정 저장**

배포 사이트에서는 브라우저에 저장됩니다. (자동 투찰 없음)

## 2. 산정 근거 (3안)

공통으로 쓰는 값:

| 용어 | 의미 |
|---|---|
| 기초금액 | **인포21C 산식의 축**. 나라장터 `bssamt`. 추정가격·배정예산과 다름 |
| 추정가격 | 참고만. 기초 칸에 넣으면 인포와 금액이 어긋남 |
| 예정가격 | 개찰 후 확정된 예정가(복수예가 등) |
| 예가사정율 | **예정가격 ÷ 기초금액** (인포21C·복수예가 분석용) |
| 투찰률(낙찰률) | **낙찰가 ÷ 예정가격** (나라장터 개찰 표시. 예가사정율과 다름) |
| A값 | 국민연금+건강보험+퇴직공제+노인장기요양+산안+품질+안전관리비 합. 시설공사 일부 적격 |
| 순공사원가 | 재료+노무+경비(+부가세). 적용 공고는 예정 중 순공사의 98% 미만 탈락 |
| 낙찰하한율 | 공고 하한 |

### 인포21C식 산식 (D안)

- 하한밀착: `기초 × 예가사정율 × 낙찰하한율`
- A값 적용: `[(기초 × 예가사정율 − A) × 하한율] + A`
- 순공사: `순공사원가 × 예가사정율 × 98%` (해당 시 더 높은 쪽을 권고)

A/B/C는 **과거 투찰률(낙찰÷예정)** 통계, D는 **예가×하한 산식**입니다. 둘을 섞어 읽지 마세요.

---

### A안 · 동일종류 낙찰

**무엇을 보나**  
같은(또는 넓힌) 범위의 **과거 낙찰 사정률** 중앙값.

**표본을 고르는 순서**

1. 같은 지역 + 같은 종류 (예: 경남 · 석면농도·비산측정)
2. 부족하면 → 전국 · 같은 종류
3. 그래도 부족하면 → 전국 · 석면 용역

**계산**

- 추천가 = 예정가격 × 사정률 중앙값(P50) (예정가 없으면 기초금액 × 사정률)
- 구간 = 같은 기준액 × P25 ~ P75

**의미**  
비슷한 종류 낙찰이 어디에 모였는지 보는 안입니다.

---

### B안 · 1년 고확률 구간

**무엇을 보나**  
최근 1년 석면 관련 낙찰의 사정률 중 **가장 많이 몰린 구간**.

**표본을 고르는 순서**

1. 같은 지역 · 최근 1년
2. 부족하면 → 전국 · 최근 1년

**계산**

- 사정률을 0.5%p 구간으로 나눔
- 건수가 가장 많은 구간의 가운데값으로 추천
- 표본이 아주 적으면 중앙값·P25~P75로 대체

**의미**  
“요즘 자주 나온 사정률 구간”을 보는 안입니다.

---

### C안 · 동일·유사 공고 이력

**무엇을 보나**

1. 같은 공고·재공고(동일 키·유사 공고명) 낙찰
2. 없으면 → 같은 종류·비슷한 금액대·유사 측정 낙찰

**계산**

- 1건: 그 사정률 × 이번 예정가격(없으면 기초)
- 여러 건: 사정률 중앙값 × 이번 예정가격(없으면 기초)
- 구간: 이력 사정률 최소~최대 (1건이면 좁은 띠)

**의미**  
같은·비슷한 공고가 과거에 어디에 낙찰됐는지 보는 안입니다.

## 3. 전문가 이의제기

산정 3안 아래에 **전문가 이의제기**가 붙습니다. 돌려 말하지 않습니다.

- **반려 수준**: 하한 미만, 표본 0건, 확정가 적자 등. 저장 시에도 한 번 더 막습니다.
- **주의/경고**: 예정가 미입력, 표본 빈약, A/B/C 괴리, 유사공고를 동일처럼 취급 등.
- **권고**: 지금 우선 대조할 안·금액.

이의제기를 무시하고 확정하면 그 책임은 담당자에게 있습니다.

## 4. 화면 경고 의미

| 표시 | 의미 |
|---|---|
| 하한·원가 조건 충족 | 공고 하한·최소 마진 조건 통과 |
| 최소 수용 마진 미달 | 원가+마진보다 낮음 → 손해 가능 |
| 공고 하한 미만 · 무효 위험 | 하한율 기준 아래로 무효·탈락 위험 |
| 표본 부족 · 참고 불가 | 쓸 이력이 없어 추천 불가 |

## 4. 사용 시 주의

1. **선정·낙찰을 보장하지 않습니다.** 참고가용입니다.  
2. 소액수의·복수예가·추첨 등 방식에 따라 가격의 역할이 다릅니다.  
3. 지역 이력이 적으면 전국 표본으로 넓히므로, 근거 문구의 **범위(경남/전국 등)** 를 확인하세요.  
4. 사업번호로 못 채우면 공고 원문의 기초금액·하한율을 직접 넣으세요.  
5. 자격·지역제한·업종은 이 도구 밖에서 이미 확인한 뒤 쓰세요.
